# 滑行艇（0.10～0.12，2026-10-12 船底斜升係數）

`/aerocore planing ...` 會生成一艘可用指令操作的滑行艇。它用來檢驗高速小艇的力模型，不是可駕駛的載具。

## 指令

需要指令權限 2。

| 指令 | 作用 |
| --- | --- |
| `/aerocore planing spawn` | 在視線前方 8 m 生成滑行艇，艏向沿視線水平方向 |
| `/aerocore planing propeller <轉/秒>` | 螺旋槳轉速 −45～45 |
| `/aerocore planing rudder <度>` | 舵角 −35～35（正值向右舷轉） |
| `/aerocore planing inspect` | 速度、C_V、V/√L、俯仰、橫傾、龍骨濕長、艉板通氣、摩擦、推力等數據（右鍵船也可） |
| `/aerocore planing debug forces` 等 | 與平台相同的受力／流場箭頭 |
| `/aerocore planing wind` / `current <x> <y> <z>` | 該船的測試風（0.12 起加在海域的風上）／附加水流 |
| `/aerocore planing clear` | 移除自己 64 m 內的滑行艇 |

建議先用 `/aerocore waves calm 128` 或 `sea` 指令建立海域，尾浪才看得到。
在常駐海域外，尾浪也會帶出臨時靜水區。

## 船

`TestPlaningBoat` 是 Fridsma（1969）系列模型放大到 1.2 m 舭寬。
- 主尺寸：長 6 m（L/b 5）、深 0.75 m、船底斜升角 20°。
- 船形：艉部稜柱形；艏部一個船寬長，平面為橢圓、龍骨沿橢圓升到甲板。
- 載重與 Fridsma 的 A 組態相同：
  - C_Δ = Δ/(ρg b³) = 0.608，即 1048 kg；
  - 重心在距艏 59% L、高 0.294 b；
  - 縱搖迴轉半徑 25.1% L。
- 因此 Fridsma 的拖曳水槽資料依 Froude 相似可直接比較；摩擦的雷諾數不同。
- 推進：0.35 m 的 Wageningen B4-70、P/D 1.4，位於艉板下方。
  - 前進象限用回歸式；
  - 其他象限用 MARIN 量測的四象限 Fourier 資料（Roddy 等 2006）。
- 舵：0.22 × 0.32 m 懸吊舵，係數見 [物理模型](PHYSICS.md)。
- 這是測試設計，不是量產船。橫搖與首搖慣量取船體外框均勻填滿的估計。

## 力模型（`PlaningDynamics`）

**垂直於龍骨的條帶力**：Zarnick（1978，DTNSRDC-78/032）的二維時域（2D+t）條帶理論。

f = D/Dt(m_a V) + C_Dc ρ b V|V|，D/Dt(m_a V) = m_a V̇ + ṁ_a V − U ∂(m_a V)/∂ξ

- V 是水垂直於龍骨衝向船底的速度，U 是沿龍骨的速度。
- 附加質量 m_a = (π/2)ρb²（k_a = 1）。
- 濕半寬 b 用 Wagner 堆水 (π/2) h cotβ，到舭為止，之後取舭寬。
- 舭濕後 ṁ_a = 0。
- 橫流阻力係數 C_Dc = cosβ。
- 附加質量項放在隱式速度解中。
- 轉動坐標系帶來的 V̇ 分量（向心加速度、法向轉動）另以顯式加入；Zarnick 的 V̇ 本身含縱搖率。
- 對流項從艉板到船艏逐條帶積分，艉板處離開船的動量 m_a U V 完整保留，與 Zarnick 相同。

**靜水壓**：
- 每個條帶剖面的完整 Archimedes 浮力。
- 艉板乾燥時，船底壓力不再被艉板面平衡，所以靜水力改為垂直於龍骨。這同時產生通氣船底應有的壓力阻力 Δ tanτ。
- 依 Mercier 與 Savitsky（1973）：艉板在 C_vT = U/√(gB_T) = 0.5 時完全通氣，約 1.5 時滑行成形。
- 力的方向，以及船側是否算入摩擦面積，在這個區間以 smoothstep 過渡。過渡方式是建模選擇，只有兩端來自文獻。

**鬚狀水花阻力（0.11）**：Savitsky、DeLorme 與 Datla（2007，Marine Technology 44(1)）。
- 駐點線前方被拋出的薄水層，在駐點線（平面上與龍骨夾 α，tanα = π tanτ/(2 tanβ)）與水花邊緣（2α）之間、直到舭的船底上摩擦。
- 兩側合計 D = ρV²C_f b² cos2α/(8 sin2α cosβ)，C_f 用 ITTC-1957，雷諾數取水層路徑 b/(2cosβ sin2α)。
- 只在龍骨已濕、舭還乾的區段存在（滑行時），施力於龍骨濕長前緣與舭開始濕的位置之間，並隨艉板通氣淡入。
- 舭在艉板處還乾時（輕載高速），水層只到艉板為止（2026-10-12；以前這時水花阻力直接變 0，阻力少約五分之一）。
- β 20°、τ 4° 時 Δλ = cos2α/(4 sin2α cosβ) = 0.40，與文獻計算一致。文獻指出它在高速滑行艇可達總阻力的 15%。

**艉板附近的壓力降（0.12，Garme 2005）**：
- 通氣的艉板後方是大氣壓，所以艉板前一段船底的壓力降到 0。Garme（2005，Ocean Engineering 32:1145）以
  μ = tanh(2.5 x_T/(0.34 B C_V)) 乘上各條帶的力，x_T 是到艉板的距離；0.34 是他以模型試驗定出的係數。
- 本模型只把 μ 乘在**靜水壓**上，並隨艉板通氣淡入（未通氣時 μ = 1）。Garme 原文也乘在動力項上；
  這樣做在 Fridsma 的 B 組態會出現大幅縱搖不穩（俯仰在 ±80° 間擺動），所以動力項維持完整。
- 與 Fridsma 吻合的 2D+t 模型（Akers 1999、Garme 2005、Ghadimi 等 2016、Ciampolini 等 2022）都以某種方式減少艉部浮力；
  0.11 以前本模型用完整 Archimedes，是航行俯仰角偏低 0.5～2.4° 的主因。

**船底斜升與濕舭長度（2026-10-12）**：
- 問題：hdfv 0.5 的 6.3 m 快艇（舭寬 2 m、船艉 19°、1226 kg、重心距艉板 2.5 m，C_Δ 0.15）在 9、12.4、14.6、18 m/s 的縱傾
  比 Savitsky（1964）低約 1°（2.7、1.8、1.4、1.0° 對 3.7、2.9、2.4、1.9°），阻力到 C_V 4 是 1.7 倍。
- 原因：
  - 相同縱傾與濕長下，2D+t 的法向力幾乎與船底斜升角無關：舭一濕，V 形截面就帶有平板的動量 (π/2)ρ(B/2)²V。
    Savitsky 的資料在 20～30° 少了平板升力的四分之一到一半（C_Lβ = C_L0 − 0.0065 β C_L0^0.6，升力係數小時減得最多）。
    固定姿態比較（C_V 4、縱傾 4°、λ 2）：模型在 4°、10°、20°、30° 的 C_L 是 0.075、0.074、0.072、0.072，Savitsky 是 0.081、0.072、0.057、0.042。
  - 2D+t 也沒有升力隨濕舭長度增加的效應（Savitsky 的 λ^0.5）。
  - 兩個誤差在 Fridsma 的長濕長互相抵消（所以 0.10～0.23 與水槽吻合），在舭靠近艉板才濕時相加：輕載、重心偏後、高速。
    升力太大 → 縱傾太低 → 濕長變長，摩擦增加，鬚狀水花阻力（約隨 1/τ 增加）變大。
- 修正：每個滑行面（無斷階的船體一個；有斷階時後體、前體各一個）的法向負載（靜水壓、動力項、附加質量、法向繞射）乘上
  k = 1 − sinβ + 0.13 L_C/B（限在 0.3～1），隨通氣淡入（`PlaningDynamics.liftFactor`、`LIFT_RECOVERY`）。
  - 1 − sinβ 是 Shuford（1958，NACA Report 1355）V 形底線性升力的斜升係數。
  - 每倍舭寬的濕舭長度 L_C 回復 0.13，是對 Savitsky 在固定縱傾與濕長下的升力擬合的（C_V 4、20° 與 30°）；10° 時舭在很前面就濕，k 約為 1。
  - 整個條帶力一起縮放，保留 2D+t 的分布與壓力中心（與 Savitsky 接近）。
  - L_C 是 Wagner 半寬到達舭的位置，在站位間內插；舭在艉板處還乾時為負值（在艉板之後）。β 與 B 取滑行面最後一站（艉板或斷階）。
    斷階還濕時，前體與後體算成同一個滑行面；這時船在駝峰，係數也隨第一個斷階的通氣淡入（與艉板的通氣相乘）。
    Sajedi 的船模在 5 m/s（C_V 2.15）沒有這個淡入時縱傾 10.1°，有時 8.0°（水槽 6.44°，同船不加斷階 8.8°、Savitsky 8.2°）。

**沒有採用的修正**：
- Zarnick 的浮力減半、力矩再減半：這是他調來配合航行俯仰角的，並讓 B 組態縱搖不穩。
- Garme 修正同時乘在動力項上（見上）。
- 船底斜升的其他做法（2026-10-12 試過，細節在 `PlaningDynamics` 的類別說明）：
  - Garme 修正或較長（2B）的艉板釋壓乘在動力項：動量在濕半寬增長處產生，大部分在 Garme 的長度之前，只改 2～10% 的升力；
    任何釋壓都讓 Fridsma LCG 70% 的縱搖不穩消失（到 V/√L 8 都穩定）。
  - Payne 的 (1 − β/2π)² 附加質量、隨斜升角的堆水係數：升力只少 11%，縱傾只動 0.1°。
  - 只用 Savitsky 的斜升比：Fridsma 的長濕長處縱傾高 1°（那裡 2D+t 缺的長度效應正好抵消它）。
  - 只縮放準穩態部分（靜水壓與前進速度的動量）：處處穩定，Fridsma LCG 70% 不再縱搖不穩。
  - 只縮放動力項、不縮放靜水壓：C_V 2 時縱傾低 0.6～1.3°。
  - 用 Savitsky 的稜柱關係由龍骨濕長推 L_C：快艇的彎曲船艏讓它在 18 m/s 縱搖不穩。

**橫向**：
- 同樣的細長體形式 F = −D/Dt(m₂₂ w)，m₂₂ 為濕剖面的 Lewis 附加質量，忽略其時間變化。
- 另加 Hoerner 橫流阻力。

**其他**：
- 摩擦：ITTC-1957，作用在濕底面上，雷諾數用龍骨濕長。
- 低速時加上零速垂直輻射記憶力（Cummins），隨艉板通氣淡出，因為零速記憶不適用於滑行中的船。

**沒有模擬**：
- 鬚狀水花以外的噴濺阻力（主噴根的動量損失）。
- 艏部外飄與彎曲艏的流動。
- 橫傾時的不對稱入水。
- 空氣升力。
- 未通氣時的艉板吃水效應。

## 尾浪與水花

- 尾浪：以濕底面（舭寬 × 龍骨濕長）上的均勻壓力，總和等於重量，驅動非定常尾浪。見 [海況與尾浪](SEA.md)。
- 白水：艉板乾燥（C_vT ≥ 1.5）時，在航跡上留下船寬的白沫，以 3.5 s 衰減。
- 水花：在舭開始濕的位置 L_C = L_K − b tanβ/(π tanτ)，依 Savitsky 的鬚狀水花模型噴出。
