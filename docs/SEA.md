# 海況、共用水面、尾浪與水花（0.10）

0.10 把「波浪」從單一規則波擴充為完整的海面層。內容分為四部分：
- 不規則海況（JONSWAP 波譜）。
- 所有讀取者共用的同一個水面：AeroCore 物體、原版實體、原版船、玩家視線、鏡頭水下霧與畫面。
- 移動船隻的 Kelvin 尾浪。
- 艏部與滑行面的水花。

這些仍是**線性理論加上經驗式**的組合，不是 CFD：
- 水方塊從不改變。
- 水面不會碎浪、不反射、也不受地形折射。

## 指令

需要指令權限 2。所有海域都以執行位置為中心，自動量測該水柱的靜水面高度與水深。

| 指令 | 作用 |
| --- | --- |
| `/aerocore waves sea <有義波高 m> <尖峰週期 s> <方向°> [半徑 m] [方向分布指數]` | 不規則海：JONSWAP 波譜，預設半徑 64 m、cos⁴ 方向分布 |
| `/aerocore waves calm [半徑 m]` | 靜水海域：沒有環境波浪，但水面由本模組重畫（尾浪看得到、原版實體讀同一水面） |
| `/aerocore waves <振幅 m> <波長 m> <方向°> [半徑 m]` | 單一規則 Airy 波（0.9 起就有） |
| `/aerocore waves info` | 列出此維度的所有海域與參數 |
| `/aerocore waves off` | 移除執行位置所在的海域 |
| `/aerocore waves clear` | 移除此維度所有海域 |
| `/aerocore platform waves sea <Hs> <Tp> <方向°>` | 以最近的平台為中心建立不規則海 |

輸入範圍：
- 有義波高 0.05～4 m，尖峰週期 1～20 s，半徑 4～128 m，方向分布指數 1～30。
- 每個維度最多 16 個海域，海域不重疊；新海域會取代與它重疊的舊海域。
- 海域資料會存檔，並同步給客戶端。

## 不規則海況（`SeaSpectrum`）

**波譜**：JONSWAP，依 DNV-RP-C205 (2010) §3.5.5。
- S(ω) = A_γ·S_PM(ω)·γ^exp(−(ω−ω_p)²/(2σ²ω_p²))。
- A_γ = 1 − 0.287 ln γ。
- σ = 0.07（ω ≤ ω_p）或 0.09（ω > ω_p）。

**γ（尖峰增強因子）**：依 DNV §3.5.5.5 由 Tp/√Hs 自動決定。
- Tp/√Hs ≤ 3.6 時為 5。
- Tp/√Hs ≥ 5 時為 1。
- 兩者之間為 exp(5.75 − 1.15·Tp/√Hs)。
- 例：Hs 1 m、Tp 6 s 時 Tp/√Hs = 6，所以 γ = 1，並不是常見的 3.3。

**方向分布**：DNV §3.5.8 的 cosⁿ。
- D(θ) = Γ(1+n/2)/(√π·Γ(1/2+n/2))·cosⁿ(θ−θ_p)，範圍 |θ−θ_p| ≤ 90°。
- 預設 n = 4，落在 DNV 對風浪建議的 2～4。湧浪建議 n ≥ 6（2010 版）。

**合成**（single summation）：
- 在 0.5～5 ω_p 之間等寬分成 32 個頻帶，約包含 99% 的變異數。
- 每個頻帶取一個分量：
  - 頻率在帶內隨機抖動，因此沒有重複週期；
  - 方向依 cosⁿ 抽樣，每個頻率只給一個方向，避免雙重求和不遍歷的問題；
  - 相位隨機；
  - 振幅取確定值 √(2SΔω)。
- 確定振幅會讓 Hs 精確，但波群統計不是高斯分布（Tucker 等 1984）。
- 0.5～5 ω_p 以外的長、短波都不包含，所以 Tz 要與截斷後的波譜比較。

**拒絕條件**：
- 陡度超過 DNV 上限 2πHs/(gTp²) ≤ 1/15。
- 最大預期波高 1.86 Hs 超過碎波高度 0.78 h。
- 每個分量也必須在線性範圍內（H/L ≤ 0.1、H ≤ 0.78 h）。

整片海域使用中心水柱的水深；深度變化造成的淺化與折射沒有模擬。

## 同一個水面（`SeaSurface`）

**擁有判定**：海域只「擁有」符合下列條件的水柱。其他水體（不同高度的水池、瀑布）維持原版行為。
- 水柱中心位於圓形範圍內。
- 靜水面高度上的方塊是水源方塊，而且不是含水方塊。
- 上方是空的、不含流體。

**水面高度**：靜水面 ＋ 漸弱後的環境波浪 ＋ 尾浪。
- 伺服器與客戶端用同一套公式和同一個時間（遊戲刻 × 0.05 s）計算。
- 海域外圈 clamp(R/4, 2, 8) m 內，振幅以 smoothstep 漸弱到 0。這是與原版靜止水面接合的處理，不是物理。

| 讀取者 | 做法 |
| --- | --- |
| AeroCore 物體（平台、測試球、測試船、滑行艇） | `WorldWaterSampler` 用同一個波場；尾浪以靜水壓方式抬高或壓低水面 |
| 原版實體（掉落物、生物、玩家） | mixin 在原版掃描水方塊之後，把屬於海域的水高度換成移動水面；眼睛是否在水中也依移動水面判定 |
| 原版船 | 水位、在水中、在水下的判定改用移動水面；船浮在原版自己的浮力規則上 |
| 鏡頭霧 | 鏡頭低於當幀水面才是水下霧 |
| 畫面 | 客戶端隱藏原版頂面，重畫整片水面 |

**原版實體的漂移**：環境波浪的水平軌道速度會帶著原版實體漂移。
- 做法：每 tick 加上 u·(1−f)/f。f 是該實體原版移動模型自己的水中每 tick 阻尼，這樣阻尼作用在「相對於水」的速度上，穩態就是水速。
- 不同實體的 f：
  - 一般生物：沿用原版 `LivingEntity.travel`，衝刺 0.9，否則 `getWaterSlowDown()`，再依水中移動效率與海豚的恩典修正。
  - 魚、守衛者、海龜、六角恐龍：0.9。
  - 掉落物：0.99 × 0.98。
  - 原版船：0.9。
- 這沒有引入新係數，但原版的移動模型本身就是遊戲模型。
- 尾浪的軌道速度沒有加入。

**原版船的沉沒規則**：只有船低於水面超過一個船身高度時，才套用原版的「水下」規則（下沉、3 秒後彈出乘客）。浪頭短暫打過船身時，交給原版隨浸深增加的浮力處理。

## 畫面（`WaveSurfaceRenderer`）

**繪製範圍**：整片海域在顯示距離內都重畫，以 16×16 方塊為一塊。

**頂點間距隨鏡頭距離變化**：

| 距離 | 間距 |
| --- | --- |
| 8 m 內 | 0.25 m（僅限最短波長 < 4 m 時） |
| 16 m 內 | 0.5 m |
| 48 m 內 | 1 m |
| 48 m 外 | 2 m（完整的 2×2 格合成一個四邊形） |

**頂點與接縫**：
- 每個頂點都是精確的波高，以相位遞推（每個分量每點一次複數乘法）計算。
- 細的區塊邊緣頂點會移到較粗鄰塊的邊線上，避免裂縫。

**快取與背面**：
- 每塊哪些格子是海面、色調與亮度會快取，每 0.5 s 更新。所以放置或拆除方塊後，最多約 0.5 s 對不齊。
- 背面只在鏡頭可能低於水面、而且 48 m 內時才畫。

**尚未在客戶端實測**：外觀、接縫、效能、Fabulous 模式都還沒看過。

## 尾浪（`KelvinWake`、`Wakes`）

### 理論

船以等速 U 沿 +x 前進時，船後遠場的自由波為：

ζ(x,y) = Re ∫ A(θ) exp(i k₀sec²θ (x cosθ + y sinθ)) dθ，k₀ = g/U²

這是線性化定常自由面條件加上 Rayleigh 輻射條件的留數（Wehausen & Laitone 1960；Newman 1977）。
其能量通量即 Havelock 波阻 R = (π/2)ρU²∫|A|²cos³θ dθ。

| 來源 | 振幅函數 | 用在 |
| --- | --- | --- |
| 細船（Michell）中線面源 σ = −2U f_x | A = −(2k₀/π) sec³θ · conj(P)，P 為 Tuck 1989 的 Michell 被積函數 | 測試船（設計水線的船形） |
| 水面壓力 p(x,y) | A = −i 4π k² P̂(k cosθ, k sinθ)/(ρg) | 滑行艇（濕底面上的均勻壓力，總和等於重量）、原版船（見下） |

**原版船的壓力**：取原版船自己漂浮時的吃水對應的靜水壓 p = ρg·0.65h，作用在它的方形底面上。
- 原版的浮力規則在浸深達船身高度 h 的 0.65 時平衡重力，所以吃水是 0.65h。
- 這是原版的規則，不是量測的船。

### 驗證（`KelvinWakeTest`）

- 測試船在 2.5、3.5、4.5 m/s 下，Havelock 能量通量與程式中獨立實作的 Michell 波阻相差在 1% 以內。研究時以 Wigley 船另行推導，兩者一致到 1e-14。
- 高斯壓力點的航跡上，橫波振幅符合駐相解 |A(0)|·√(2π/(k₀d))，誤差 10% 以內。
- 橫截面最大波高位於 19.47°（Kelvin 角）± 2° 內。
- 網格化的波型與逐點積分一致（3% 以內）。
- 船艏前方沒有波。
- 速度過低、波長短於可解析範圍時，不產生尾浪。

### 遊戲中的做法

**波型網格**：
- 每個來源依目前速度取對應的定常波型，以 0.5 m 網格儲存，最短波長 2 m（每波長 4 點）。
- 長度為 8 個橫波波長，限制在 24～96 m 之間；最後 25% 漸弱。這是截斷，不是物理衰減。

**速度分格與計算**：
- 速度以 3% 為一格。
- 波型在背景執行緒計算，同一設計同時只算一個。
- 換速度格時，在 1 秒內交叉淡入淡出。
- 停船或離水後尾浪淡出。

**船隻的近似**：
- 波型剛性地跟著船的位置與運動方向。這是等速直線航行的近似：加速、轉彎時船後的尾浪不是真正的歷史。
- 尾浪只以水面高低作用在其他物體上，屬靜水壓近似；它的軌道速度和動壓沒有加入。
- 物體不會感受到自己的尾浪，因為那已算在它的阻力裡。

**靜水區**：
- 在常駐海域以外，每個有尾浪的來源會帶著一塊不存檔的靜水區。
- 靜水區中心以 16 m 對齊，半徑以 32 m 為一級，最大 128 m。
- 它讓尾浪可以被畫出來、也能被原版實體感受。
- 靜水區移動時，客戶端只重建受影響的區塊。

## 水花（`BowSpray`、`SprayRenderer`）

**排水型船艏**：用 Noblesse 等（2008、2013）的關係。
- F = U/√(gD)，D 為吃水，α 為水線進流半角。
- 浪峰高 Z_b = (U²/g)·min(2.2 tanα/((1+F)cosα), 1/2)。
- 4.4 tanα/cosα > 1 + F 時浪峰不穩定溢流，才產生水花。
- 水沿船艏以 U 偏轉離開：
  - 水平分量為前向 U(1−cosα)、側向 U sinα；
  - 垂直速度 √(2gZ_b)，正好到達浪峰高。
- 原版船是方形艏（α = 90°），所以浪峰高達 Bernoulli 上限 U²/(2g)。

**滑行底面**：
- 噴根角 α_s = atan(π tanτ/(2 tanβ))，出自 Savitsky 1964。
- 鬚狀水花以船速、在與龍骨夾 2α_s 的方向離開，出自 Savitsky、DeLorme、Datla 2007。
- 頂點高度 V_V²/(2g)，其中 V_V = V sinα_s + V cosα_s sinα_s sinβ_E，β_E = atan((1−2/π)tanβ)，出自 Savitsky 與 Morabito（經 Ghadimi 2015 轉述）。

**畫面上的水滴**：
- 在真實重力下作拋物運動，不計空氣阻力，落回靜水面為止。
- 每側每 tick 3 顆、總數上限 1500，並有 ±15% 的初速散布。這只是顯示預算，不是水花的質量通量。
- 尚未在客戶端實測。

## 效能

- 水面取樣改為預先編譯的波場：一次計算多欄位的相位遞推，並讓同一水柱的壓力與速度共用指數運算。
- 32 分量海況中，一次 7×7 球體取樣：
  - 優化前約 140 µs；
  - 各次 GameTest 量到 64～85 µs，最近一次 78 µs。
- 平台每 tick 約做 50 次這種取樣。
