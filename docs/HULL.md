# 測試船（0.9／0.10）

6 m 圓舭小艇，用來在遊戲裡看細長船體模型：阻力、轉向、側滑與迴旋。它和平台一樣是**實驗工具，不能駕駛**，
只能用指令設定螺旋槳轉速與舵角。船形與質量是測試設計，沒有實船資料；模型細節見 [物理模型](PHYSICS.md) 的「細長船體」一節。
高速小艇（會滑行的硬舭船）請用 0.10 的 [滑行艇](PLANING.md)；尾浪、水花與海況見 [海況與尾浪](SEA.md)。

| 項目 | 值 |
| --- | --- |
| 船長／寬／深 | 6 m／1.4 m／0.9 m（甲板在局部 y 0.45 m，船中龍骨 −0.45 m，往船首抬高） |
| 質量 | 1200 kg，重心在設計浮心上方的水線下 |
| 設計吃水 | 約 0.36 m（局部水線 y ≈ −0.09 m），C_B ≈ 0.46、C_P ≈ 0.66 |
| 阻力 | ITTC-1957 摩擦 × Holtrop–Mennen 1+k（約 1.28）＋ Michell 造波阻力表 |
| 螺旋槳 | 直徑 0.4 m 的 B3-65（與平台同一套：前進象限回歸式，其他象限 MARIN 量測四象限資料），轉速 −20～20 轉/秒 |
| 舵 | 0.30×0.50 m 懸舵，舵角 −35～35°，正值右轉；Whicker–Fehlner 升力斜率；在槳流中時來流加速 |
| 接觸 | 鋼殼：對方塊（視為岩石）摩擦 0.4、Thornton 速度相依恢復係數；與其他物體鋼對鋼 |
| 尾浪與水花 | 設計水線船形的 Michell 細船源，以雙體壓力驅動非定常尾浪（0.11；0.10 為定常 Kelvin 波型）；Noblesse 艏波碎波判據決定水花與白沫 |
| 波浪輻射 | 船體分成 6 段，當作點吸收體陣列（只有垂直起伏） |

## 先試這個

找一片至少 20×10 格、2 格深的開放水面，朝向水面：

```text
/aerocore hull spawn
/aerocore hull propeller 12
/aerocore hull inspect
/aerocore hull rudder 20
/aerocore hull debug all
```

`spawn` 在前方 8 m 生成，船首朝你的水平視線方向。12 轉/秒時約 3.3 m/s（Fn ≈ 0.42）；舵 20° 會以約 18 m 的直徑右轉、速度略降。
`inspect` 或右鍵顯示速率、前進速度與 Fn、船首方位、轉首率、橫傾、縱傾、排水量、阻力，以及螺旋槳 J、推力、軸功率與舵力。
也可以站到甲板上，船會載著你移動（見 [平台說明](PLATFORM.md) 的「原版實體站上甲板」）。

## 指令

| 指令 | 用途 |
| --- | --- |
| `/aerocore hull spawn` | 前方 8 m 生成；每個維度最多 8 艘 |
| `/aerocore hull inspect` | 狀態與控制數據 |
| `/aerocore hull propeller rev_per_s` | 螺旋槳轉速，−20～20 轉/秒；負值倒車 |
| `/aerocore hull rudder degrees` | 舵角，−35～35°，正值右轉 |
| `/aerocore hull debug off/forces/flow/all/relative/all_relative` | 粒子箭頭，與平台相同（藍色為升力） |
| `/aerocore hull wind x y z`／`current x y z` | 測試風（0.12 起加在海域的風上）／附加水流，每軸 −10～10 m/s |
| `/aerocore hull clear` | 移除 64 格內自己生成的測試船 |

測試船不存檔，區塊卸載或重開世界後消失；12000 tick 後自動移除。波浪使用世界波浪區域（`/aerocore waves ...`）。

## 限制

- 排水型模型：速度高到開始滑行（這艘船約 6 m/s 以上）時，阻力仍以 Michell 外推，不會出現滑行升力或船尾下沉。
- 操縱導數只在 Clarke 的 Y'_v、N'_v 上對準；轉首阻尼與 KVLCC2 實測相差約 20～45%（見物理模型）。
- 舵是準穩態的升力面；沒有螺旋槳側向力、船體伴流、舵失速遲滯或空化。
- 垂直輻射用點吸收體近似，水平與橫搖的輻射阻尼沒有；橫搖只靠舭部橫流阻力阻尼。
- 接觸用沿龍骨、舭部與舷緣的球；與方塊單向、與其他 AeroCore 物體雙向。

## 驗證

JUnit：設計浮態與比例、橫傾回正力矩、12 轉/秒的穩定速度與舵 20° 的右轉（合理性範圍，沒有實測可比）。
GameTest（24×16 m 水池）：在設計水線上平浮、排水量等於設計值；螺旋槳推動前進、正舵角使船首右轉，升力箭頭有顯示。
畫面（船體網格、舵與槳的轉動）與在甲板上站立需在遊戲中實測。
